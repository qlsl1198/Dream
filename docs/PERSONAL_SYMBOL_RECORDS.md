# 내 꿈에 등장한 상징

도감 상세에서 관련 꿈 수와 최신 세 건의 날짜·본문 발췌를 표시한다.
‘앨범에서 모아보기’는 기록 탭에 상징 필터를 적용한다. 필터를 해제하면
기존 검색어와 필터를 복원한다. 기록 카드를 열면 기존 상세 편집 흐름을 사용한다.

데이터 계약: `findPersonalSymbolRecords`는 원문에서 확인된 증거만 사용하며
해석 텍스트·저장된 상징·태그에만 있는 언급은 제외한다. 한 꿈당 한 번만 집계한다.
도감 상세를 열 때만 로컬 저장소를 읽고, 저장 스키마와 네트워크는 바꾸지 않는다.

기반/병합 순서: `feat/diverse-dream-landscapes` → `feat/dream-album-first` (cfbd1e9)
→ `feat/personal-symbol-records`. main 병합과 TestFlight 배포는 하지 않는다.

검증 명령: Node 22로 `npm test`, `npm run typecheck`, `git diff --check`.
Node 22에서 세 검사 모두 통과했다. 회귀 케이스는 본문만 검색하는지,
같은 단어가 여러 번 나와도 한 꿈을 한 번만 세는지, 알 수 없는 상징의 빈 결과를 확인한다.
iOS 네이티브 빌드와 실기기 검증은 하지 않았다.
Expo 웹(8098), Aside 390×844: 도감에 본문 근거가 있는 두 샘플만 표시되고,
앨범 이동, 기록 상세 열기, 필터 해제 후 전체 목록 복귀를 캡처로 확인했다.
브라우저 최종 응답은 시간 초과되어 콘솔 전체와 태블릿 검증은 완료로 기록하지 않는다.
수동 재현: 본문에 바다가 있는 두 꿈과 해석에만 바다가 있는 꿈을 만든다.
도감에서 바다를 열면 두 건만 표시되는지 확인한다. 앨범에서 모아본 뒤
카드 상세를 열고, 필터를 해제해 원래 검색 상태로 돌아가는지 확인한다.
