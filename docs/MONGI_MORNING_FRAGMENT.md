# 몽이의 아침 한 조각

기반: main `6e59eeb` → `feat/dream-evidence-first` (`024c130`) → `feat/mongi-morning-fragment`.
홈에서 짧게 기억나는 낱말을 남기는 모드다. 감정·태그·해석 버튼은 잠시 숨기고
기존 본문 입력과 `dream_draft`를 그대로 사용한다. 별도 기록이나 저장 키를 만들지 않는다.
닫기 버튼은 기존 저장 큐에서 본문과 부가 필드의 저장이 성공한 뒤에만 닫는다.
실패 시 현재 입력을 유지하고 다시 시도할 수 있다. 초안은 앱을 다시 열어도 복원되며,
앨범 기록은 사용자가 정식 저장을 눌렀을 때만 생성된다.

재현: 기존 초안에 감정과 태그를 넣고 아침 한 조각에 들어간다. 한 단어를 더 적어
저장하고 닫은 뒤 새로고침한다. 본문·감정·태그가 그대로이고 앨범 건수가 늘지
않는지 확인한다. 별도 기기 권한이나 서버 연동은 없다.
