# 몽이 시작 안내

## 게임형 말풍선 추가

`feat/mongi-dialogue`는 `feat/mongi-tutorial`을 기반으로 한다. 문장을 한 글자씩 표시하고 문장부호에서 잠깐 쉰다. 말풍선 또는 ‘바로 읽기’는 현재 문장을 완성하며 다음 입력에서 단계를 이동한다. 배경 전환·개인정보 모달·동작 줄이기·네이티브 스크린리더에서는 즉시 전체 문장을 표시한다. 타이머는 화면 종료 때 정리한다. 웹 보조기기에는 전체 aria-label을 제공한다.

별도 작업 사본에 잠금 파일 기준 `npm ci`로 의존성을 복원한 뒤 전체 타입 검사와 회귀 테스트가 통과했다. iOS Hermes 번들도 생성됐다. 아래 iCloud 대기 기록은 복원 전 이력이다. 최초 정적 안내의 320/390/820px 화면, 이전/다음·완료·재실행 생략·설정 재생·개인정보 모달은 브라우저에서 통과했다. 새 타이핑 화면 및 네이티브 빌드 검증 결과는 별도 배포 기록을 따른다.

- `feat/mongi-tutorial`은 `fix/compact-home-header` → `feat/companion-emotions` → `main` 순으로 의존한다.
- 첫 실행 및 튜토리얼 버전 1을 보지 않은 기존 사용자에게 5단계 안내를 표시한다.
- 다음·이전·건너뛰기를 제공하고, 완료/건너뛰기 후에는 다시 자동 표시하지 않는다.
- 설정 → 몽이 사용 안내에서 재생할 수 있다. 재생은 기록이나 개인정보 동의 상태를 변경하지 않는다.
- 말풍선 내용에 맞춰 몽이의 표정이 바뀐다. 음성 합성이나 외부 통신은 추가하지 않았다.
- 안내 완료를 개인정보 동의로 간주하지 않는다. 개인정보 처리방침은 별도 링크로 열 수 있다.
- 앱 데이터 전체 삭제와 OnboardingService.reset은 안내 버전 키도 제거한다.
