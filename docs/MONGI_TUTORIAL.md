# 몽이 시작 안내

- `feat/mongi-tutorial`은 `fix/compact-home-header` → `feat/companion-emotions` → `main` 순으로 의존한다.
- 첫 실행 및 튜토리얼 버전 1을 보지 않은 기존 사용자에게 5단계 안내를 표시한다.
- 다음·이전·건너뛰기를 제공하고, 완료/건너뛰기 후에는 다시 자동 표시하지 않는다.
- 설정 → 몽이 사용 안내에서 재생할 수 있다. 재생은 기록이나 개인정보 동의 상태를 변경하지 않는다.
- 말풍선 내용에 맞춰 몽이의 표정이 바뀐다. 음성 합성이나 외부 통신은 추가하지 않았다.
- 안내 완료를 개인정보 동의로 간주하지 않는다. 개인정보 처리방침은 별도 링크로 열 수 있다.
- 앱 데이터 전체 삭제와 OnboardingService.reset은 안내 버전 키도 제거한다.
