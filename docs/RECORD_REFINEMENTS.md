## 변경

- 기본 해석 상징 매칭에 단어 경계·조사 검사를 적용하고 모호한 단독 별칭을 제외했다. 기본 테마도 같은 매칭 근거를 사용한다. 단서가 없으면 구체적인 의미를 붙이지 않는다.
- 상세 화면에 본문 단어·주변 문맥을 보여준다. 이는 사전의 어휘 매칭 근거이며, AI 본문의 모든 주장을 검증하거나 의미 해석의 정확성을 보장하지 않는다. 보수적 규칙 때문에 합성어·활용형 일부는 놓칠 수 있다.
- 본문·감정·태그를 편집한다. 공백 기록을 거부하고 ID·기록 날짜를 보존한다. 본문/감정 변경 시 기존 해석을 보존하되 수정 전 기준임을 표시한다. 재해석은 사용자 선택이다.
- 재해석 저장 직전 원래 본문·감정과 일치하는지 검사한다. 삭제 또는 동시 편집된 기록에 오래된 결과를 덮어쓰지 않는다.
- 본문 외 감정·유형·생생함·수면·태그도 기기 내 임시 저장한다. 기존 plain-text 초안은 복원 후 버전 접두어 형식으로 이전한다. 읽기/검증 실패 시 입력을 활성화하거나 깨진 초안을 덮어쓰지 않는다.
