# 몽이 깜빡임 보완 및 표정 확장

## 변경과 브랜치 의존 순서

`fix/mongi-flicker` → `feat/mongi-expression-pack` → `fix/mongi-sprite-sizing`.
기반은 빌드 13 배포 기록 커밋 `f46fe84`이다. main은 별도로 병합하지 않는다.

- 4.6초마다 180ms 동안 전체 이미지를 다른 포즈로 바꾸던 가짜 눈깜빡임을 제거했다.
- 기본 이미지와 두 표정 아틀라스를 계속 마운트하고, 로딩 완료 상태를 확인해 표시한다. fadeDuration은 0이다.
- 브라우저 검증에서 기본 이미지가 원본 크기 1230×1278로 배치되어 114×114 뷰포트에서 보이지 않는 문제를 발견했다. 기본 이미지에도 명시적인 width/height를 적용했다.
- 수줍음·호기심·졸림·속상함·걱정·다짐 6종을 추가했다. 기존 상태를 포함하면 13종이다.
- 슬픔/두려움/분노 선택은 각각 다른 표정으로 연결한다. 터치 순환은 행복 → 수줍음 → 놀람 → 호기심 → 졸림 → 평온이다.
- 자동으로 새 표정을 빠르게 순환하지 않는다. 사용자 선택과 터치, 해석/저장 상태에만 반응한다.
- 새 이미지는 내장 도구로 생성한 로컬 RGBA PNG이며, 앱의 외부 AI 통신이나 SDK를 추가하지 않았다. 생성 프롬프트와 배치는 `assets/dream-world/MONGI_EXTRA.md`에 기록했다.

## 검증 (2026-11-04)

Node 22.23.3에서 전체 TypeScript 검사, `npm test`, `git diff --check`, iOS Hermes 번들 생성을 통과했다. PNG의 1536×1024 크기·RGBA 형식, 12개 프레임 인덱스와 두 아틀라스 좌표, 반응 우선순위를 회귀 검사한다.

Browser plugin이 없어 Aside 스킬의 내장 Playwright 호환 브라우저를 사용했다. 대상은 `http://localhost:8083/`, 화면은 390×844 / 320×700 / 820×1180이다.
