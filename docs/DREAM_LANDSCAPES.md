# 드림로그 풍경 다양화 — 작업 인수인계

## 배경과 현재 범위

드림로그는 Expo/React Native 기반 꿈 기록 앱이다. 꿈 이미지는 기기에 포함된
일러스트를 선택해 표시한다. 이전에는 장소 단서가 없는 거의 모든 기록이
‘고요한 달의 정원’으로 떨어졌다. 이 작업은 이미지 선택과 카드 표기를 개선한다.
꿈 저장 형식, 해석 모델, 별자리, 출시 설정은 변경하지 않는다.

## 구현 구조

- `src/utils/dreamWorld.ts`: 본문 → 추출 상징 순서로 단서를 찾는다. 가족·친구 등
  일반 인물 단서는 낮게 가중한다. 단서 없는 본문은 정규화한 문자열을 해시해
  7개 분위기 풍경으로 분산한다. 빈 본문의 기본값은 달의 정원이다.
- `src/components/dreamArtwork.ts`: 기존 7종과 신규 6종을 각기 다른 에셋에 연결한다.
  꿈 앨범과 상세 화면이 같은 분류기를 사용한다.
- `src/components/DreamSceneCard.tsx`: 단서 기반과 분위기용 풍경 안내를 구분한다.
  풍경별 제목 3종(총 39종)을 사용한다. 동일한 본문과 상징으로 다시 열면 동일한
  이미지와 제목이 나온다. 다른 기록이 같은 이미지를 쓸 수 있다.
- 기존 기록도 열 때 새 규칙을 적용한다. 데이터 마이그레이션이나 네트워크 호출은
  없다. 장면을 실시간 생성하거나 실제 꿈의 장소를 판별하지 않는다.

## 새 에셋과 제작 방식

`assets/dream-world`의 신규 PNG는 내장 이미지 생성 도구로 사전 제작했다.
공통 프롬프트: 3:2 가로 수채화, 종이 질감, 남색·보라와 금빛 하이라이트,
장면은 위쪽 2/3, 앱 글자가 올라갈 아래쪽은 어둡고 단순하게, 글자·사람·UI 없음.

## 재현 및 검증

Node 22에서 `npm ci`, `npm test`, `npm run typecheck`, `git diff --check` 실행.
2026-11-23: Node 22.23.3에서 회귀·타입·공백 검사 통과. Expo 웹 번들 성공.
Aside로 localhost:8096의 앨범 → 상세 흐름을 390×844 및 820×1180에서
합성 기록으로 확인했다. 도서관·기차·축제 이미지와 분위기용 문구의 렌더링을
캡처로 확인했다. 최종 브라우저 자동 검사 보고서는 대기 시간이 초과되어
콘솔 전체와 새로고침 상호작용은 이 시점에 통과로 기록하지 않는다.
네이티브 iOS 빌드와 실기기 검증은 이 작업에서 하지 않았다.
회귀 케이스는 신규 장면의 한국어·영어 분류, 짧은 단어 오탐, 본문 우선,
모호한 입력 60개에서 7종 분산, 동일 텍스트 안정성, 제목 및 에셋 수를 확인한다.
수동 검증: 서로 다른 장소의 샘플 꿈을 앨범에서 열고 상세 이미지가 다른지,
모호한 꿈의 문구가 구분되는지, 재실행 후 이미지가 유지되는지 확인한다.
