# Mongi extra expressions

Asset: `mongi-emotions-extra.png`, 1536×1024 RGBA, 3 columns × 2 rows.
Generated using the built-in image generation tool (no app API integration).
References: existing `mongi.png` identity anchor and `mongi-emotions.png` style/scale reference.
Cells: shy, curious, sleepy / sad, worried, determined.
These are explicit UI reactions, never predictions of the user's mental state.
The original atlas is preserved. Runtime preloads both atlases and retains the base fallback image.

## Prompt

Use case: stylized-concept. Asset type: production game character sprite atlas, six NEW emotion variants for Mongi moon rabbit. Reference image 1 is identity anchor; image 2 is existing six-sprite style and scale reference, NOT an edit target. Generate a new genuinely transparent RGBA image, landscape 1536x1024, exact 3 columns by 2 rows of equal square 512x512 cells, no grid lines and no labels. Same adorable ivory fluffy lop-eared rabbit, lilac inner ears and paw pads, golden crescent on forehead, holding same glowing golden star. Match watercolor plush texture, warm soft light and character identity. Every cell has full seated body centered at same scale and baseline with at least 28px transparent padding all around; do not crop ears or feet, do not let sprites cross cell boundaries. Change primarily FACE/eyebrows/mouth and tiny paw gestures; keep body proportions, size, star and pose stable to avoid visual jumps. Row1 left SHY: blushing cheeks, bashful sideways eyes, small smile; center CURIOUS: bright open eyes, one eyebrow raised, inquisitive smile; right SLEEPY: half-closed drowsy eyes, tiny yawn, peacefully hugging star. Row2 left SAD: gently downturned eyebrows and mouth, glossy sad eyes but NO tears, tender not distressed; center WORRIED: concerned eyebrows, small worried mouth, holding star reassuringly, not frightened; right DETERMINED: confident small eyebrows, brave friendly smile, not angry or aggressive. Six clearly different expressions readable at 130px. No additional props, no speech bubbles, no text, no watermark, no floating particles, no background scene, no colored rectangles, no checkerboard baked in; actual transparent background.
